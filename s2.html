2　通解长什么样

齐次方程组 x = k₁ξ₁ + k₂ξ₂ + ⋯　，　k₁, k₂, ⋯ ∈ R
非齐次方程组 一个特解 ＋ 上面这一族

3　极大无关组

4　伴随矩阵与逆

A⁻¹ = 1|A| A* （|A| 是 A 的行列式）

其中 Aij 是代数余子式：划掉第 i 行第 j 列，剩下的行列式再乘 (−1)i+j。

5　含参方程组：无解 / 唯一解 / 无穷多解

系数秩 < 增广秩 无解
两个秩相等，且 = 列数 唯一解
两个秩相等，且 < 列数 无穷多解，自由变量 = 列数 − 秩

判断只看一件事：把增广矩阵化成阶梯形后，有没有出现左边全 0、右边不为 0 的行。出现就无解。
